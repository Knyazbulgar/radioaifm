# Radio AI FM — мобильное приложение

PWA-приложение станции [aifm.su](https://aifm.su). Ставится на домашний экран iPhone и Android и работает как обычное приложение: эфир 24/7, обложка, история, расписание, контакты.

## Что внутри

- Живой поток `https://radio.aifm.su/listen/aifm/radio.mp3` (192 kbps MP3)
- Название и обложка текущего трека из AzuraCast API
- Следующий трек и история эфира
- Сетка программ по московскому времени
- Новости, ведущие, форма обратной связи
- Кнопка «Установить» (Android Chrome) и поддержка Add to Home Screen на iOS
- Воспроизведение в фоне и на экране блокировки (Media Session)

## Как поставить на смартфон прямо сейчас

1. Залейте папку `aifm-app` на хостинг **по HTTPS** — лучше всего в каталог сайта, например `https://aifm.su/app/`.
2. Откройте этот адрес на телефоне.
3. **Android (Chrome):** появится баннер «Установить» или меню → «Установить приложение».
4. **iPhone (Safari):** «Поделиться» → «На экран Домой».

PWA не ставится с `file://` и с HTTP без SSL. Нужен именно https.

### Вариант: сразу на aifm.su

Скопируйте содержимое этой папки в корень GitHub Pages (рядом с текущим `index.html` сайта) **или** в подпапку `/app/`.

Если кладёте в `/app/`, слушатели открывают `https://aifm.su/app/`.

## Публикация в магазинах (по желанию)

PWA уже достаточно для повседневного использования. Если нужны иконки в Google Play / App Store:

1. Установите [Capacitor](https://capacitorjs.com/):
   ```bash
   npm init @capacitor/app
   npx cap add android
   npx cap add ios
   ```
2. Скопируйте файлы из этой папки в `www/`.
3. Соберите APK / IPA в Android Studio / Xcode.

Для Play Store понадобятся: иконка 512×512, скриншоты, политика конфиденциальности (на сайте уже есть).

## Файлы

```
index.html              — оболочка приложения
css/app.css             — стили
js/app.js               — плеер, API, навигация
sw.js                   — офлайн-оболочка (поток не кэшируется)
manifest.webmanifest    — имя, иконки, standalone
offline.html            — заглушка без сети
icons/                  — иконки PWA
```

Поток и API не кэшируются — эфир всегда живой.
